View freelancer profile, transaction history, and connects balance.

Actions:

- transactions: Get transaction/earnings history. Covers the selected account's accounting entity only, so a person with more than one account sees each separately. Params: ace_ids (array of accounting entity ID strings, optional — auto-resolved from org context if omitted), from_date (string, yyyy-mm-dd), to_date (string, yyyy-mm-dd, max 53 weeks from from_date — split longer questions into one call per year) — at least one date required. accounting_entity_id (string, optional — single ACE ID shortcut, auto-resolved if omitted). limit (number, default 25, max 200 — returns the most recent N transactions; total_count reports how many exist). Optional params are refinements: do not silently invent values. If the user makes a broad request, briefly surface the most relevant available refinements and proceed with only the required params plus context the user already provided. Ask before applying optional filters when the user asks for a selective result such as best, top, cheapest, near me, urgent, or only. After returning results, mention useful refinements the user can apply.
- connects_balance: Get connects balance and recent usage history. Shows current balance breakdown (free, paid, rollover) and recent connects transactions with job titles. balance is the general Connects wallet; product_credits (when present) are ad credits spendable only on the named product and are NOT included in it — report them separately, never summed. Page with next_cursor until hasMore is false. Params: limit (integer, 1–10, default 10), cursor (string, optional — next_cursor from the prior call).

## update_profile

read_only: false

Manage freelancer profile: title, overview, availability, employment, skills, languages, education, and other experience. WRITE OPERATION — REQUIRES EXPLICIT USER CONFIRMATION

WRITE OPERATION — REQUIRES EXPLICIT USER CONFIRMATION.
Returns a preview for review — call confirm_preview to execute after explicit user approval. Only one pending preview is held per action type at a time: starting this action again before the current preview is confirmed replaces it without executing it, so wait for the user's decision on the pending preview before starting another change of this type.

Actions:
- update_title: Update the public freelancer profile title/headline. Params: title (string, required — maximum 70 characters).
- update_overview: Update the public freelancer profile overview/summary. Params: overview (string, required — maximum 5000 characters).
- update_availability: Set freelancer availability. Params: capacity (string, required — one of: fullTime, partTime, lessThen, notSure, rangeOfHours, none).
- set_skills: Replace the freelancer's complete main-profile skill set. Call get_profile first and pass the full revised set, not only additions. A main profile supports at most 20 skills. Names are resolved to Upwork ontology skills before a draft is created; custom skills are not supported. Unresolved names are shown as rejected in a partial draft; if none resolve, no draft is created. Pass an empty skills array to remove all skills. Params: skills (array of strings, required, maximum 20).
- add_employment: Add work experience entry. Params: company_name (string, required), job_title (string, required), role (string, required — role description, max 50 characters), start_date (string, required — yyyy-mm-dd), city (string, required), country (string, required — ISO code such as US; not a full name), end_date (string, optional — yyyy-mm-dd), description (string, optional).
- update_employment: Update a work experience entry. Pass the record id plus ONLY the fields you want to change — the tool reads the existing record and merges your changes, so unchanged fields are preserved automatically (updateFreelancerEmploymentRecord is a full-record replace upstream). Get the id from get_profile. Params: id (string, required — employment record ID), role (string, optional — max 50 characters; kept as-is when omitted), company_name (string, optional), job_title (string, optional), start_date (string, optional — yyyy-mm-dd), end_date (string, optional — yyyy-mm-dd), description (string, optional), city (string, optional), country (string, optional — ISO code such as US; not a full name).
- remove_employment: Remove work experience entry. Params: id (string, required — employment record ID).
- add_language: Add language proficiency. Params: language_code (string, required — ISO 639 code e.g. 'en', 'es', 'fr'), language_name (string, required — English name e.g. 'English', 'Spanish'), proficiency (string, required for English only — one of: BASIC, CONVERSATIONAL, FLUENT, NATIVE_OR_BILINGUAL). Other languages are added without a proficiency level.
- update_language: Update language proficiency level. Params: language_code (string, required — ISO 639 code e.g. 'en', 'es'), language_name (string, required — English name e.g. 'English', 'Spanish'), proficiency (string, required for English only — one of: BASIC, CONVERSATIONAL, FLUENT, NATIVE_OR_BILINGUAL). Other languages are added without a proficiency level.
- remove_language: Remove a language from profile. Params: language_code (string, required — ISO 639 code e.g. 'en', 'es').
- add_education: Add education record. Params: institution_name (string, required), area_of_study (string, optional), degree (string, optional), start_date (string, optional — yyyy-mm-dd), end_date (string, optional — yyyy-mm-dd), comment (string, optional).
- update_education: Update education record. Params: id (string, required — education record ID), institution_name (string, optional), area_of_study (string, optional), degree (string, optional), start_date (string, optional — yyyy-mm-dd), end_date (string, optional — yyyy-mm-dd), comment (string, optional).
- remove_education: Remove education record. Params: id (string, required — education record ID).
- add_other_experience: Add other experience (publications, awards, etc). Params: subject (string, required), description (string, required).
- update_other_experience: Update other experience entry. Params: id (string, required), subject (string, optional), description (string, optional).
- remove_other_experience: Remove other experience entry. Params: id (string, required).
