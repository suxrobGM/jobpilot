# Getting started

JobPilot has two parts. The website holds your profile, resumes, and
applications. The agent runs on your computer and does the searching and
applying. Setup takes about ten minutes.

## What you need

- A [Claude Code](https://claude.com/claude-code) or [Codex](https://openai.com/codex)
  subscription. The agent runs on it, so you don't need an API key.
- Windows, macOS, or Linux.
- [Node.js](https://nodejs.org) 22 or newer.

## 1. Install the plugin

The [install page](/install) has these commands with copy buttons.

In Claude Code:

```text
/plugin marketplace add https://github.com/suxrobGM/claude-plugins
/plugin install jobpilot@sukhrob-claude-plugins
```

For Codex, in a terminal:

```text
codex plugin marketplace add suxrobGM/codex-plugins
codex plugin add jobpilot@sukhrob-codex-plugins
```

## 2. Run setup

In a new session, run `/jobpilot:setup` in Claude Code or `$setup` in Codex.

Setup installs the terminal host, a small program that runs the agent, then
starts it and opens JobPilot in your browser. Running setup again updates the
host.

The agent button at the bottom of the left rail opens the **agent drawer**.
That's where you watch the agent work and switch between Claude Code and
Codex.

To start the agent again later:

- **Windows:** press **Start agent** in the agent drawer. The button appears
  after the agent's first run.
- **macOS and Linux:** run setup again, or type `jobpilot` in a terminal.

The agent checks for updates each time it starts.

> Claude Code starts on the latest Sonnet model and Codex on GPT 6 Luna.
> Bigger models use up your weekly limit much faster without sending more
> applications. The [FAQ](/docs/faq) explains why.

## 3. Create your account

[Sign up](/register) and confirm your email. Onboarding has three steps:

1. **Resume.** Upload a PDF. The agent reads it into your profile: work
   history, education, skills, contact details. It takes a minute or two. If
   the agent isn't running, the file is saved and you can fill in the details
   yourself.
2. **Personal.** Details from the resume fill any profile field you left
   blank. Check them and press **Save & continue**.
3. **Connect agent.** Checks that the agent from step 2 is running. Press
   **Finish** to open the Pilot.

Application forms are filled from your profile. Scoring and tailoring use your
resume. Keep the address the same in both; the resume page warns you when
they differ.

Change your profile later under **Settings → Profile**. Work authorization,
salary, references, and equal-opportunity answers are under
**Settings → Application answers**.

The agent also suggests an improved version of your resume. Open it from the
card on your resume under **Resumes**, press **Review** to compare, then
**Apply rewrite** or **Discard**. Your original PDF is kept, so
**Re-extract from PDF** always brings the original text back.

## 4. Set up the Pilot

The **Pilot** page tells you what it still needs before it can work alone,
one step at a time:

1. **Goals.** Describe the job you want, for example "ML engineer, new grad,
   Pittsburgh or remote, visa sponsorship". The Pilot builds its searches
   from this.
2. **Address.** Application forms ask for it.
3. **Board logins.** Save them on the **Job boards** page so the agent can
   sign in. See [Credentials](/docs/credentials).

Then:

- Choose a rule under **Brief** in the Overview to set your daily limit and
  minimum match score.
- [Connect Gmail](/docs/email-setup) so the Pilot can read replies and
  sign-in codes. Optional, but recommended.
- Turn on **Autopilot** in the top bar.

To see how it scores before it applies anywhere, leave autopilot off and ask
in the message box: "find ML engineer jobs in Pittsburgh but don't apply yet".

Jobs it finds land in **Pipeline**. Read [The Pilot](/docs/pilot) next.
