# FAQ

## Do I need an API key?

No. The agent runs on the Claude Code or Codex subscription you already have.
JobPilot doesn't include any AI keys and doesn't charge you anything.

## Which AI model should I use?

A mid-range one, like **Claude Sonnet 5.5** or **GPT 6 Luna**.

We don't recommend top models like **Claude Opus 5.5**. Applying to jobs is
mostly reading postings and filling in forms, which doesn't need much
reasoning. A top model spends longer thinking at every step, so it uses up
your weekly limit much faster and doesn't send any more applications. With
the Pilot running all day, it could use a whole week's limit in a day or two.
Mid-range models are also quicker, so more gets done.

JobPilot already starts Claude Code on the latest Sonnet and Codex on GPT 6
Luna. If you want a different model, type `/model` in either one.

## Where does the agent run?

On your computer. The dashboard is a website, but the terminal host, the AI
session, and the browser that does the applying all run on your machine. You
can watch everything it does in the agent drawer.

## How do I start the agent again after it stops?

On Windows, press **Start agent** in the agent drawer. On macOS and Linux, use one of
the two commands the agent drawer shows: run setup again in Claude Code or Codex, or
type `jobpilot` in a terminal. Both commands work on Windows too.

The button only appears on Windows, and only after the agent has run once.
[Getting started](/docs/getting-started) explains why.

## Which job boards does it work with?

Any board you can open in a browser. New accounts start with LinkedIn, Indeed,
Hiring Cafe, and We Work Remotely. You can add Wellfound, Y Combinator (Work at
a Startup), Welcome to the Jungle, Hacker News "Who's Hiring", Remote OK,
4 Day Week, and Upwork from the board picker, or add any other site from the
Settings → Job boards.

## How many jobs does the Pilot apply to each day?

As many as your daily limit allows, one per task. The server enforces the
limit, not just the AI's instructions, so it holds even if something goes
wrong partway. The networking limit works the same way. Change it under
**Rules** on the Pilot page.

## How does the Pilot decide what to do first?

The server sorts the to-do list before every task. Your messages come first,
then work you asked for with a button, then questions you've just answered,
interview replies, applications (best matches first), networking, and finally
searching for new jobs. You steer it with your goals, rules, and messages. See
[the Pilot](/docs/pilot).

## Will the Pilot send messages or post anything without asking me?

Only the things you've allowed: applications up to your daily limit, and
networking emails if you set email to **Auto-send**. LinkedIn messages and
public posts always wait for your approval, and interview replies are always
drafts for you to check. The server enforces these rules.

## What if my computer sleeps or crashes in the middle of a task?

You don't lose anything. The Pilot does one task at a time and saves the
result before moving on. If a task crashes partway, it times out and goes back
on the to-do list. The agent starts again by itself after a reboot or when the
computer wakes up.

## Can I use JobPilot myself while the Pilot is running?

Yes. Every button works as normal, and buttons simply ask the Pilot for that
work, so it runs next. If you type in the terminal yourself, the Pilot waits
3 minutes after your last keystroke before starting anything new, so the two
of you don't collide. **Hand back** on the Pilot page ends the wait early.

## Can I see exactly what it did?

Yes. The Pilot's thread shows every task with its result. **Watch** shows the
task in progress step by step, from any device. **Settings → Diagnostics**
has the full run history, what each run cost in tokens, and an export.

## How long do I have to answer a question?

As long as you like for most questions; the job involved just waits. Login
codes are the exception. They expire after about five minutes, and if you miss
one the Pilot skips that job. You only get asked for codes the agent can't
read itself, from SMS or an authenticator app. Codes sent by email are read
from your inbox without bothering you. To get questions on your phone, turn on
notifications under **Settings → Notifications**.

## Can JobPilot read and send email?

Yes, through a Google OAuth client you create. See
[Email setup](/docs/email-setup). Reading lets it match replies to
applications and pick up sign-in codes. Sending is for networking. It can't
delete email. JobPilot works without email too, you just don't get those
features.

## What about captchas?

The agent handles checkbox and text captchas by itself. For picture puzzles it
needs a 2Captcha or CapSolver key, which you add under
[Credentials](/docs/credentials). Without one, it skips the job and tells you
why.

## How do I update the agent?

When a new version comes out, a banner appears in the agent drawer. **Update now**
installs the new terminal host and restarts it, which ends any session that's
running. You'll rarely need it, though, because the agent checks for updates
every time it starts.

The plugin updates separately. The same banner has a **Prefer to update
manually?** link with the commands for your provider.

## Can I switch between Claude Code and Codex?

Yes, at any time, from the agent drawer. Both use the same plugin and the same skills.

## Where are my resumes stored?

In your JobPilot account, not on your computer. That includes the PDFs you
upload and every tailored version. You can edit the content under
**Documents**.

## Does the agent change my resume?

Not unless you say so. Two things can change resume content, and both need
your approval:

- After you upload a resume, `review-resume` suggests a rewrite and lists
  each change. Press **Review** to compare it with your current text, then
  **Apply rewrite** or **Discard**. Your PDF stays as it is, so
  **Re-extract from PDF** brings back the original.
- For each job, `tailor-resume` makes a separate copy and leaves your main
  resume alone. If your resume isn't a good fit for the job, the copy may also
  reorder, combine, or drop entries, or move a project into your work history.

Neither one can make up an employer, a date, or a number. The server rejects
a rewritten bullet that contains a number the original didn't have, works out
the dates of combined roles from the real ones, and won't move a project that
has no dates. Anything it can't confirm is flagged for you.

## Why do I keep getting rejected without interviews?

Look at how fast the rejections come. If they arrive within a day, a person
probably never read your resume. An automatic filter turned you down, usually
over work authorization, location, or years of experience. These things help
more than another resume edit:

- **Check the sponsorship question.** If you need visa sponsorship, most large
  companies filter on it before anyone reads your application. The agent skips
  postings that say so, but most companies don't say so.
- **Apply to fewer, better-fitting companies.** Fifty applications to
  companies that filter you out get you fifty rejections.
- **Use networking.** A referral skips the automatic filter.
- **Connect your email,** so rejections show up in your pipeline and you can
  see your response rate.

## How do I delete my data?

The dashboard doesn't have a delete button yet. Until it does, email
[suxrobgm@gmail.com](mailto:suxrobgm@gmail.com) from the address you signed up
with and ask for your account to be deleted. Deleting an account
removes your profile data and destroys your encryption key, so your stored
secrets can never be read again.
