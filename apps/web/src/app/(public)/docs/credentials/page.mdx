# Credentials

The agent signs in to job boards as you, so it needs your logins for them. You
can also give it a key for a captcha-solving service. Both go under
**Settings → Credentials**.

## Board logins

Add a **Board login** for each board you've added under **Boards**. When a
board asks the agent to sign in, it uses that board's login. The
**Default login** is used for any board that doesn't have its own, which is
handy if you use the same email and password in several places.

Some boards email you a code when you sign in. If your
[email is connected](/docs/email-setup), the agent reads the code from your
inbox and carries on.

## Captcha services

The agent can handle simple captchas by itself, like checkboxes and warped
text. Picture puzzles from reCAPTCHA, hCaptcha, and Turnstile need a paid
service. Add an API key for [2Captcha](https://2captcha.com) or
[CapSolver](https://capsolver.com) under **Settings → Credentials** and the
agent uses it when it has to. Without a key, the agent skips that job and
tells you why.

## How your secrets are stored

Board passwords, captcha keys, and your Gmail client secret and tokens are
all encrypted with a key that belongs only to your account. They're only
decrypted on the server when the agent needs them. Once you save one, the
dashboard never shows it again. When an account is deleted, its key is
destroyed and nobody can read the stored secrets.

## Auto-apply settings

Three related settings live on the next tab, **Settings → Profile**. They
apply to every auto-apply campaign:

- **Min match score (0-100):** jobs that score lower are skipped.
- **Max applications per campaign:** the most applications one auto-apply
  campaign will send. This is separate from [the Pilot's](/docs/pilot) daily
  limit, which counts every application sent that day.
- **Default start date answer:** what the agent says when a form asks "When
  can you start?"
