# Credentials

The agent signs in to job boards as you, so it needs your logins. You can also
give it a key for a captcha service.

## Board logins

The **Job boards** page shows which boards have a login. **Add login** saves
one for a board. The **Default login** is used for any board without its own,
which helps if you use the same email and password in several places.

When a board emails you a sign-in code, the agent reads it from your inbox if
[email is connected](/docs/email-setup).

## Captcha services

The agent solves checkbox and text captchas itself. Picture puzzles from
reCAPTCHA, hCaptcha, and Turnstile need a paid service: add a
[2Captcha](https://2captcha.com) or [CapSolver](https://capsolver.com) key on
the **Job boards** page. Without one, the agent skips the job and tells you
why.

## How your secrets are stored

Board passwords, captcha keys, and your Gmail secret and tokens are encrypted
with a key that belongs only to your account. They're decrypted on the server
only when the agent needs them, and the website never shows them again after
you save them. Deleting your account destroys the key, so nobody can read them
afterwards.
