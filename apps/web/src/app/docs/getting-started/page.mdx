# Getting started

JobPilot has two halves: your dashboard on the web, and an agent that runs on
your own machine. Setup takes about ten minutes.

## What you need

- A [Claude Code](https://claude.com/claude-code) or [Codex](https://openai.com/codex)
  subscription. The agent runs on it, so JobPilot needs no API keys.
- Windows, macOS, or Linux.

## 1. Install the plugin

Add the plugin to the provider you use. The [install page](/install) has
copy-paste commands for both. In Claude Code:

```text
/plugin marketplace add https://github.com/suxrobGM/claude-plugins
/plugin install jobpilot@sukhrob-claude-plugins
```

In Codex, from a shell:

```text
codex plugin marketplace add suxrobGM/codex-plugins
codex plugin add jobpilot@sukhrob-codex-plugins
```

## 2. Run setup

Start a new provider session and run the `setup` skill: `/jobpilot:setup` in
Claude Code, `$setup` in Codex. It installs the local terminal host, starts
the agent, and opens the dashboard. Run it again any time: when a host is
already installed, `setup` upgrades it to the latest release instead.

```text
/jobpilot:setup
$setup
```

From here the agent dock (the terminal column down the right side of the
dashboard) shows everything the agent does, and you can switch providers there
any time. If the terminal host ever breaks, the [install page](/install) has a
one-line installer to repair it.

The first start is always `setup`. Once the agent has run, how you start it
again depends on your operating system:

- **Windows.** The dock shows a **Start agent** button whenever the agent is
  stopped. The agent registers a `jobpilot://` handler with Windows on every
  run, and the button opens that link.
- **macOS and Linux.** Nothing registers a handler there, so the dock offers
  two commands instead: run `setup` again in Claude Code or Codex, or type
  `jobpilot` in any shell.

Whichever way you start it, the agent checks for a new release first, so it
comes back on the latest version.

> Claude Code sessions default to Sonnet. On Codex, pick a mid-tier model
> yourself: GPT 5.6 Terra. Top-tier models eat your weekly usage limits far
> faster without applying to more jobs. [Why](/docs/faq).

## 3. Create your account

Go to [jobpilot.suxrobgm.net](https://jobpilot.suxrobgm.net), sign up, and
verify your email address. Onboarding is three steps.

1. **Resume.** Upload a PDF. The agent on your machine reads it and turns it
   into structured content: contact details, work history, education, skills.
   Watch it happen in the dock; it takes a minute or two. Without a running
   agent (on a phone, say) the upload is kept and you fill the rest in by hand.
2. **Personal.** Extraction copies your name, email, phone, links, and city
   into any profile field that is still empty. It never overwrites something
   you typed. Check what it filled in, add what it missed, then press
   **Save & continue**. The profile powers form filling; the resume powers job
   scoring and tailoring.
3. **Connect agent.** This checks that the host you installed in step 2 is
   running and shows the install commands again if it isn't. Press **Finish**
   and you land on the workspace with the dock open.

Everything can be changed later under **Settings**.

While you finish onboarding, the agent also drafts an improved version of your
resume: a sharper summary, outcome-first bullets, tidier skill groups. It waits
for you on the resume page under **Documents**, as a card counting the suggested
changes. Press **Review** to read the old and new text side by side, then
**Apply rewrite** or **Discard**. Your uploaded PDF is never touched, so
**Re-extract from PDF** always gets you back to the original.

> Keep your profile address and resume header in agreement. Recruiters read the
> resume, but application forms and cover-letter headers come from your profile,
> and the resume page flags any disagreement.

## 4. Run your first campaign

`setup` is the only command you type. From here on you drive the agent from
the dashboard, and it works in the dock while you watch.

Start gentle: search first, apply after review. Press **New campaign**, enter
what you're looking for, and pick a board. The composer opens on **Auto-apply**,
so switch the mode to **Search** for this first run. The agent searches, scores
each role against your resume, and saves the matches to the campaign. Review the
ranked list, then approve the ones worth applying to.

Once you trust the scoring, leave the mode on **Auto-apply**. It searches,
scores, and applies one job at a time until the board is exhausted, you pause
it, or it reaches the campaign's application cap (**Settings → Profile**).

Every application lands in your workspace, where it moves from applied to
offer.

You can also skip the campaign-by-campaign work. The Pilot writes its own
searches from your goals, applies within a daily cap, handles replies, and only
interrupts you for decisions it can't make, like a salary question on a form.
